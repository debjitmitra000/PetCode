# codepet — Monkey Animation Sprite Specification

I am building a VS Code pet extension called **codepet**.

I already have one finished animal with a fixed art style.
Now I want a **MONKEY** in the EXACT SAME STYLE and animation system.

IMPORTANT:
This is NOT normal illustration work.
This is a CONSISTENT GAME/SPRITE CHARACTER SYSTEM.

The monkey must remain the SAME CHARACTER in every frame.

---

# STRICT STYLE RULES (VERY IMPORTANT)

* Pixel art only
* Visible pixels
* No smooth painterly rendering
* No semi-realistic rendering
* 1:1 square image
* Character occupies most of canvas
* Minimal empty space
* Same outline thickness everywhere
* Same shading style across all frames
* Soft cute shading, not realistic
* Same lighting direction in all frames
* Same eye style in all frames
* Same proportions in all frames
* Same body structure in all frames
* Same colors in all frames
* Same emotional style in all frames
* Facing LEFT always
* Cute chibi proportions
* Large expressive eyes
* Small compact body
* Simple readable silhouette

---

# BACKGROUND RULES

VERY IMPORTANT:

* Use SOLID background color only
* NO gradients
* NO texture
* NO grain
* NO noise
* NO painterly background
* NO lighting on background

Background must be:

* single flat solid color
* different green than grass

Grass must be:

* simple pixel grass platform
* single-color/simple 2-tone pixel grass
* no realistic grass
* no textured ground
* no shadows blended into ground

---

# MONKEY DESIGN RULES

The monkey must ALWAYS remain the SAME character.

DO NOT redesign it between frames.

Maintain:

* same face
* same muzzle
* same nose
* same eye shape
* same ear shape
* same tail type
* same proportions
* same fur pattern/colors

Monkey design style:

* cute baby monkey
* slim body
* expressive oversized eyes
* soft warm brown tones
* lighter beige face/belly/hands/feet
* small rounded monkey ears
* long curved monkey tail
* tail must feel flexible and expressive
* tiny monkey hands/feet, NOT dog paws
* monkey nose/mouth area must not resemble a dog muzzle
* no dog anatomy
* no dog tail
* no dog paws

Think:

* cute cartoon baby monkey
* playful but sleepy/emotional
* game sprite companion

NOT:

* realistic monkey
* gorilla
* furry ape
* monkey-human hybrid

---

# IMPORTANT ANATOMY RULE

DO NOT copy dog anatomy.

When adapting poses:

* capture the POSE ENERGY
* capture the EXPRESSION
* capture the MOTION

BUT rebuild the pose using MONKEY anatomy.

This should NEVER look like:
“dog body with monkey face”

That is WRONG.

---

# TAIL RULE

Tail is EXTREMELY IMPORTANT.

The monkey tail should:

* be long
* flexible
* expressive
* curl naturally
* swing dynamically during running/jumping
* help express emotion

DO NOT use:

* dog tail
* fox tail
* stiff tail

---

# HANDS & FEET RULE

Monkey hands/feet must look like monkey limbs:

* tiny fingers implied in pixel form
* grasp-like hands
* rounded monkey feet
* more flexible than dog legs

Do NOT use dog paws.

---

# NOSE RULE

Avoid:

* shiny dog nose
* thick black nose outline
* large protruding muzzle

Monkey face should be flatter and softer.

---

# EXPRESSION RULE

Expressions should feel:

* cute
* readable
* emotionally exaggerated
* animation-friendly
* simple and iconic

Do not over-render details.

---

# IDLE — 2 FRAMES

What it represents:
Monkey is calm, waiting, doing nothing.

## Frame 1 — idle_1.png

* Body: sitting position, relaxed monkey posture
* Legs folded naturally under body
* One hand resting on ground
* Head facing LEFT
* Eyes fully open with tiny white highlights
* Small calm smile
* Tail curled beside or behind body
* Overall feeling: calm, curious, alert

## Frame 2 — idle_2.png

Everything identical to frame 1 except:

* Eyes half-closed for a slow blink

Swap at:
800ms
